## Competitor table and discussion

Notes so far:
- Easy Concierge (Brittany PMS, run by a conciergerie): API Meublés module "en préparation"; addresses already normalised to BAN/INSEE; 25 EUR HT/month for 5 units + 3 EUR per extra unit; 99 EUR for 15 units; 20 clients, 170+ units (18 Sep 2026) ([easy-concierge.fr](https://easy-concierge.fr/)).
- Biloki: dashboard centralises numbers; consolidated night counter across OTAs with alerts; reports per unit/period/OTA; does not claim API Meublés transmission; no public price ([Biloki blog](https://blog.biloki.fr/fr/blog/api-meubles-proprietaire-airbnb-abritel-guide-2026)).
- HostLegal (Toulouse): rents its carte G to conciergeries, contract pack, dashboard, legal support, Le Meur watch; from 49.90 EUR HT/month; no API Meublés, NER or 120-night features ([hostlegal.fr](https://www.hostlegal.fr/)).
- Software seen on conciergerie websites (Majordia): Superhote 48, Lodgify 42, Avantio 34, Smily 28, Beds24 26 ([Majordia](https://www.majordia.fr/ressources/observatoire-conciergeries-lcd)).
