# Deep pass for thin reports

These reports were written when the first session's 200-search cap was nearly spent (4–14
searches each). Each deep-pass session redoes 1–3 of them with its own search budget.

## Agent instructions (deep pass)

Follow `research/method/agent-instructions.md`, with these changes:

- Budget: up to 60 searches for your country (the session cap of 200 is shared by the agents in
  your session). WebFetch is still blocked; use WebSearch, extended mode where useful.
- First read the existing report for your country. Use it as a starting point, not a limit:
  - screen the industries it lists as "not screened" / "not covered", plus any others from the
    brief that fit the country;
  - verify or correct its claims marked "unverified", especially competitor names and pricing;
  - search in the local language(s).
- Rewrite the same file in place as one complete report in the brief's format (not an
  appendix). Keep earlier findings that still hold, re-score where the evidence changed, and add a
  short "Pass history" note at the end saying this is a deep pass and what changed.
