# Luxembourg: Offline (quiet) industries pass

**Researched:** 2026-10-05 · **Searches:** 3 attempted of 20. One was refused with a usage-limit error, so I stopped searching as the instructions require. The other two returned almost nothing about Luxembourg.

**Bottom line:** This is a short, honest report with **no opportunity recommended**. The search tool cut out after one refusal, and the two searches that ran found little that was specific to Luxembourg. Luxembourg has about 670k residents, so each quiet industry has tens to a few hundred operators. Many of the matching obligations also have a free state substitute. The screening table below rests mainly on prior knowledge that I could not verify in this session. Every row is marked **unverified** unless a source is cited. Treat the table as a to-do list for a later pass, not as findings.

## 2. Strongest opportunities

**None.** No quiet industry in Luxembourg reached the evidence bar. That bar is an official obligation, offline evidence, a market count and a substitute check. The two leads in the existing country report remain the best for Luxembourg. Both concern cross-border labour (posting checks for main contractors and telework day counting), and neither is a quiet industry.

## 3. Rejected

- **Household-employer payroll/declarations:** the likely substitute is the CCSS's own simplified declaration for household employers. This is unverified because the search was refused.
- **Chimney-sweep compliance router:** the duty is set by communal police regulations and is fragmented. But enforcement is weak ("poorly known", per Paperjam), there is no filing step to an authority and the trade is tiny.
- **Brocante / second-hand dealer registers:** no Luxembourg police-register duty was found. The only official artefact found is the city's brocante stand form, which is occasional and consumer-side.
- **Beekeepers, tattoo studios:** too few paying operators in a 670k-resident country.

## 4. Method notes

- The search budget was effectively lost: one of the first three searches was refused with a usage-limit error, so I stopped as instructed.
- French-language regulator queries ("registre", "règlement grand-ducal") return mostly results from France and Swiss cantons (Neuchâtel, Valais). Future queries should add `site:legilux.public.lu`, `site:guichet.public.lu` or `site:ccss.lu` to stay in Luxembourg.
- For any follow-up, the obvious structural limit stays: quiet industries in Luxembourg have very few operators. Any idea would need to be a Greater Region product (LU + Lorraine + Wallonia + Saarland/Rhineland-Palatinate) to be viable.
