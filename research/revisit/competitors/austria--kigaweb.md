# KigaWeb (Austria) - competitor check for C0056 (private kindergarten subsidy reporting)

## Verdict: not-a-real-competitor

KigaWeb is a parent/family communication app (messages, events, absence reports), not a subsidy-reporting tool. Confidence is moderate: only 4 of 6 searches ran (the 5th hit a usage limit), and no vendor site was reached.

## Evidence
- The App Store listing describes KigaWeb as a way to exchange messages, events and information between families and the childcare facility. It offers push notifications, direct messages, parent chat, event registration, and absence reports through a calendar. It has dynamic translation in almost 100 languages and runs on iPhone and Android. Source: https://apps.apple.com/de/app/kigaweb/id1533787536 (via search snippet).
- The same snippet says the app is part of the "KitaWeb" module suite, described as web-based software for administrative and pedagogical tasks of facilities. I did not verify what KitaWeb does for funding or reporting, or whether it is sold in Austria. Status: unverified.
- A search for Austrian private-kindergarten funding and software returned only state guidelines and application forms. Examples: Lower Austria (https://www.noe.gv.at/noe/Kindergaerten-Schulen/Richtlinie_Foerderung_fuer_Noe_Privatkindergaerten.pdf) and Salzburg (https://www.salzburg.gv.at/fileadmin/SP-Dateien/bildung_/Documents/ZEKIP/Antrag%20Bef%c3%b6rderung%202023_2024_w9140-WEB.pdf). Neither mentions KigaWeb. Separately, a NÖ government page about a staged rollout of digital kindergarten administration exists (https://www.noe.gv.at/noe/Stufenweise_Ausrollung_von_Digitalem_Kindergartenverwaltu.html). I did not read it, so whether it is a state tool that competes with this idea is unverified.
- Funding is set per state. Lower Austria pays EUR 45,000 per group per year to private operators (from a search summary of the guideline). Applications go through state forms by 31 December. This suggests the reporting is state-specific and form-based.
- Momentum: no release dates, acquisitions or shutdown news found. Unverified.

## Complaints
None found. The one review search ("KigaWeb Erfahrungen Bewertung Kritik") returned only unrelated companies (Kigata, Gigawebzone). Google Play, Reddit and local forum reviews were not found or checked.

## Pricing
Not found. Unverified.

## Fit gaps
- It has no subsidy or funding-reporting function visible in the listing. It is a parent communication app.
- No evidence it handles Austrian state-specific funding forms. Unverified for the KitaWeb suite.

## Opening
KigaWeb does not occupy the private-kindergarten subsidy-reporting niche, so C0056 should not have been dropped because of it. The remaining risks are the KitaWeb suite (unverified) and state digital administration tools (NÖ page unread).
