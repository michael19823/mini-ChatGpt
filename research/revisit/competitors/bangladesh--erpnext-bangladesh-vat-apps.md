# ERPNext Bangladesh VAT apps (bangladesh) - competitor to C0081 (NBR VAT software: Mushak 6.3, 6.1/6.2, 9.1)

## Verdict: weak

## Evidence
- The only concrete product found is ECOSIRE's "erpnext bangladesh vat mushak", a build-to-order Frappe app, not a self-serve product. It covers Mushak 6.3 challan auto-created from Sales Invoice, Mushak 9.1 return as a query report, VAT/SD tax templates, bilingual Bangla/English print formats, and VDS capture/certificates. Source: https://ecosire.com/apps/erpnext/erpnext-bangladesh-vat-mushak
- It runs only inside a self-hosted/bench ERPNext install (v15, v16), so the buyer must already run ERPNext. Same source.
- No complaints, reviews or forum threads found. A search for Frappe forum discussion returned only ECOSIRE pages. Searches were limited: the Bangla-language search failed (usage limit hit), so only 2 English searches ran. Local-language coverage: unverified.
- Momentum: could not verify (no release history or dates seen). Treat as unverified.
- Mushak 6.1/6.2 registers: the search summary mentioned "purchase and sales registers" only generally; unverified whether they are fully covered.

## Pricing
- Indicative price from $399 USD, quote-based, per ECOSIRE page (same URL). Plus ERPNext hosting/implementation costs (unverified amounts).

## Fit gaps
- Requires ERPNext; no standalone option for small shops using Excel/paper.
- Custom build/quote model, not self-serve; likely no mobile or NBR e-filing integration (unverified; not mentioned).
- Not a broad community-maintained product evident in the results.

## Opening
A self-serve, standalone Mushak 6.3/9.1 tool for small VAT-registered businesses not on ERPNext is not served by this offering.
