# Cameroon: paiesoft hr_payroll_cameroun (commercial Odoo module)

Dropped idea: C0165 (generating the CNPS and DGI monthly DIPE payroll declarations).

## Verdict: beatable

It is a real product that already generates the CNPS magnetic DIPE, but it is an Odoo Enterprise add-on, so it is out of reach for small employers without Odoo.

## Evidence
- Listed on Odoo Apps as "CameroOn payroll - Paie Cameroun" by paiesoft, for Odoo versions 14.0 to 17.0 (https://apps.odoo.com/apps/modules/17.0/hr_payroll_cameroun). It runs on Odoo Online, Odoo.sh and on-premise, and requires Odoo Enterprise (per the search summary of the listing).
- The listing says it adds a magnetic DIPE declaration (text file) that follows CNPS specifications, remote CNPS declaration and a dashboard for downloading files. It makes no mention of a DGI DIPE file; I found none (unverified).
- It also offers loans, biometric timekeeping, hourly/daily/monthly processing, in-kind benefits, leave management and batch payslip printing.
- Support is via https://paieafricaine.online. A search for reviews of that site returned nothing.
- A separate Odoo module, l10n_cm_payroll_cnps (https://apps.odoo.com/apps/modules/18.0/l10n_cm_payroll_cnps), turned up in two searches. A summary said some software generates upload-ready CNPS and DGI DIPE files, "one example" being an Odoo module. I did not confirm which module that was, so treat it as unverified and as a possible second competitor.
- Complaints: none found (3 searches, French and English). No app-store, forum or news complaints about this product. Absence of reviews is not evidence of quality.
- Momentum: the listing shows versions up to 17.0. I did not see 18.0 or 19.0 versions of this module (unverified). I found no dates for updates.

## Pricing
- $1,025.01 on the Odoo 17.0 listing (per the search result). This is a one-off module price, on top of Odoo Enterprise licensing. That is expensive for a small Cameroonian employer. Whether the price recurs is unverified.

## Fit gaps
- Needs Odoo Enterprise, so a company has to adopt a full ERP. Poor fit for small firms and accountants running payroll for several clients.
- No evidence of DGI DIPE output or of a standalone, mobile or offline tool (unverified).
- No public user reviews, so there is little proof it works in practice.

## Opening
A cheap standalone tool that produces both the CNPS and DGI DIPE files for small employers and accountants, with no Odoo needed.
