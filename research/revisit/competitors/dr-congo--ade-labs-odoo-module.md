# ADE Labs Odoo module (dr-congo) - idea C0260 (DR Congo facture normalisee for SAP/Sage/Odoo)

## Verdict: not-a-real-competitor (for DR Congo; moderate confidence)

## Evidence
- The only ADE Labs product found is "ADELABS e-MECeF SFE" on the Odoo Apps store (apps.odoo.com/apps/modules/19.0/adelabs_emecef_sfe). Its description says it is DGI-certified and automates standardised sales invoices and credit notes with security elements. e-MECeF is the Benin DGI scheme, not the DRC one. The search snippet did not name Benin or DRC, so the target country is partly inferred (unverified).
- No search result tied ADE Labs to DR Congo, to the DRC "e-MCF"/"e-UF" devices, or to the DRC DGI. Three searches (French and English) returned nothing on an ADE Labs DRC module. I did not open the Odoo page, so its full feature list is unverified.
- DRC context: the DGI announced the first phase of the Facture Normalisee on 5 Sept 2024. It is a pilot with selected companies, using "e-UF" (no billing software) and "e-MCF" (with billing software) devices (Sovos, search snippet). Mandatory rollout status was not confirmed.
- Other vendors seen: Innowise has a "SAP DRC e-invoicing" compliance page (innowise.com/fr/blog/sap-drc-e-invoicing/). Sage and SAP FNE offerings found are for Cote d'Ivoire, not DRC. Odoo partner BCC Services (Kinshasa) is listed on odoo.com. I did not check whether any of these offer a DRC e-MCF connector.
- Complaints: none found. No reviews, app-store ratings or forum threads on ADE Labs turned up.

## Pricing
- No ADE Labs price found (unverified). For comparison, a different vendor's e-MCF Benin module on Odoo Apps showed about $378.98 (v17) and $380.49 (v19) per a search snippet.

## Fit gaps
- No evidence of DRC support at all, so for DRC buyers it is not a competing product.
- Odoo-only: no SAP or Sage coverage.
- Momentum: a v19.0 listing exists, which suggests it is current. Unverified beyond that.

## Opening
The ADE Labs module does not appear to cover DRC, so the DRC facture normalisee gap for SAP/Sage/Odoo is open. The real competitors to check are Innowise (SAP) and local Odoo partners such as BCC Services.
