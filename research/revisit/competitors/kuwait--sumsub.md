# Sumsub (Kuwait) - commercial, no URL given

Killed idea: C0526, generic KYC/sanctions screening APIs (Shufti Pro, Sumsub, LexisNexis, Focal).

## Verdict: strong

Sumsub is a global, actively marketed KYC/AML platform with an Arabic-region page. It is a real
competitor to any generic KYC/sanctions API. It leaves a gap only for Kuwait-specific workflows.

## Evidence
- Search 3 (Trustpilot/reviews) hit the usage limit; I found no reviews or complaints. This is not
  evidence that none exist. Complaints: not checked.
- Sumsub claims 14,000+ ID document types in any country/language (sumsub.com ID verification
  page, via search snippet). Whether Kuwait Civil ID is explicitly supported: unverified.
- Sumsub has an Arabic-region KYC/AML page, https://sumsub.com/ae/kyc-compliance/ (appeared in
  Arabic-language search). Kuwait-specific coverage: unverified.
- Momentum: active. 2026 pricing pages, a 2026 new-products webinar and 2026 event pages
  (e.g. Istanbul Fintech Week 2026) are indexed.
- Kuwait context: Kuwait has a PACI mobile ID app with a three-tier verification system
  (mobileidworld.com). I found no sign that Sumsub integrates with it (unverified).

## Pricing (published, per search snippets of https://sumsub.com/pricing/)
- Basic: $1.35 per verification, $149/month minimum (non-regulated businesses).
- Compliance: $1.85 per verification, $299/month minimum (adds AML and proof-of-address checks).
- 14-day free trial with 50 checks.
- Third-party comparisons (e.g. didit.me) claim cheaper alternatives; those are vendor marketing.
- Affordable for small regulated firms, but a minimum commitment applies.

## Fit gaps
- Nothing verified as missing. Possible gaps, all unverified: Kuwait Civil ID/PACI integration,
  Kuwait-specific AML rules (CBK/FIU, MOCI DNFBP reporting formats), Arabic-first UX,
  local-currency (KWD) billing, local support.
- It is an API/SDK for onboarding; it is not an AML compliance workflow tool for DNFBPs such as
  accountants or real-estate agents.

## Opening
Little room as a generic KYC API. Any opening is a Kuwait-specific compliance workflow (goAML-style
reporting, Civil ID/PACI, Arabic UX) layered on top, not a competing verification engine.
