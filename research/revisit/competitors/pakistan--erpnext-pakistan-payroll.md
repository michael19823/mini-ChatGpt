# ERPNext Pakistan payroll (pakistan)

Killed idea: C0736 (EOBI/PESSI/SESSI contribution compliance)

## Verdict: beatable

It is a build-to-order add-on sold by one reseller. It needs an ERPNext install, has no found user reviews, and has no filing output (only a bank disbursement file).

## Evidence
- ECOSIRE lists an "ERPNext Pakistan Payroll" Frappe app, built to order, for ERPNext v15 and v16. It adds FBR tax slabs, an EOBI component (employee and employer shares against a configured wage ceiling), and per-province PESSI/SESSI rates chosen by work location. It also exports bank salary-disbursement files (fixed-width or CSV). Source: https://ecosire.com/apps/erpnext/erpnext-pakistan-payroll
- The page mentions no EOBI/PESSI/SESSI filing or challan/return format. It describes calculation only. This is from the search snippets; the page itself was not fetched.
- Other Pakistan payroll options that already cover EOBI/PESSI: SoftVirtue (https://softvirtue.com/software/payroll-software), an Odoo l10n_pk_payroll module (https://apps.odoo.com/apps/modules/18.0/l10n_pk_payroll), HysabOne (https://hysabone.com/products/payroll-attendance/). So the idea faces several rivals, not only this one.
- Momentum: the product targets current ERPNext versions (v15 and v16), so it is maintained, but it is a niche reseller listing. Anything about the install base is unverified.
- Complaints: none found. Searches in English and Urdu, including one aimed at the Frappe forum, returned only ECOSIRE product pages. No Frappe forum posts, reviews or Reddit threads turned up.

## Pricing
- Indicative price from $249 USD (build-to-order, per ECOSIRE). Whether this is one-time or recurring is unverified.
- It also needs an ERPNext instance, hosted or self-hosted, and someone to configure it.
- For comparison from the searches: standalone Pakistani payroll software from PKR 80,000, or PKR 3,499 per month on a SaaS plan (SoftVirtue/other vendors; exact vendor for each figure unverified).

## Fit gaps
- It requires ERPNext, so it does not suit a small firm that only needs payroll and compliance.
- Setup is build-to-order, with no self-serve sign-up.
- No EOBI/PESSI/SESSI return or filing output is mentioned (unverified).
- No mobile or offline use, and no Urdu-first UI, is mentioned (unverified).

## Opening
A standalone, self-serve tool that produces EOBI/PESSI/SESSI contribution reports and filing files for small employers, without an ERP, beats a $249+ custom ERPNext add-on. Rivals such as SoftVirtue and Odoo modules still need to be checked.
