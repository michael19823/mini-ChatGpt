# Eko-Soft (Poland) - competitor check for C0775 (Poland BDO waste paperwork)

## Verdict: weak

Eko-Soft appears to be a niche desktop program for waste processors. Four searches (2 Polish, 2 English) found no evidence of BDO API integration, no published price, no reviews and no sign of recent development. The evidence is thin, so the verdict is low-confidence.

## Evidence
- Product "Eko-Soft Ewidencja odpadów" is described as software for firms that collect, recover or dispose of waste: sorting plants, RDF producers, composting plants, biogas plants, bioremediation, plastic recyclers. Features listed: records for any number of companies, waste generation, waste record and transfer cards, statistics, contractor register, export to Word/PDF/Excel, data archiving module. Source: https://www.instalki.pl/download/programy/windows/firma/programy-branzowe/ewidencja-odpadow-przetwarzanie-odpadow/
- It is listed as a Windows download with a demo (form, then emailed link) on a download portal, which suggests a classic desktop product. Source: https://www.instalki.pl/download/programy/producent/eko-soft/
- The same vendor has other Polish environmental-compliance products: Opłaty Środowiskowe (environmental fees) and Ewidencja Opakowań (packaging records). Sources: https://www.instalki.pl/download/programy/windows/firma/programy-branzowe/eko-soft-oplaty-srodowiskowe/ and https://www.instalki.pl/download/programy/windows/firma/ewidencja-srodkow-trwalych/eko-soft-ewidencja-opakowan/
- The search snippets did not mention BDO API integration for Eko-Soft. Absence in snippets only; whether it integrates is unverified. The BDO API itself has been open since Q4 2019 (source: https://rev-log.com/pl/?p=797).
- Complaints: none found. No app-store, Trustpilot, Reddit, forum or news complaints surfaced. The searches could not reach the vendor's own site, so this does not mean the product is well liked.
- Momentum: unverified. No release notes, funding or acquisition news found. The download-portal listing gives no dates in the snippets.

## Pricing
Not found. The vendor site was not reached and no price is published in the results. Unverified.

## Fit gaps
- Target is waste processors (sorting, RDF, composting, biogas, recycling), not the typical small waste producer who files BDO paperwork. A small producer buyer is probably not served (inferred from the product description).
- Appears to be Windows desktop, with no mention of web, mobile or cloud use (unverified).
- No mention of BDO API sync, KPO cards or annual reports in the snippets (unverified).

## Opening
A web/mobile BDO tool for small waste producers and holders, with BDO API sync, looks open here. Eko-Soft targets processors and shows no visible BDO-sync, cloud or review presence.
