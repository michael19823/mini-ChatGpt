# Romania: SINTETIC project (idea C0814: Romania EUDR timber DDS)

## Verdict
not-a-real-competitor

## Evidence
- Searches (English and Romanian) found no product, vendor or publicly described project called "SINTETIC" for EUDR, timber or wood traceability in Romania. Its identity is unverified; the triage data lists it as type "generic" with no URL.
- A search for "SINTETIC proiect Romania software" returned only general Romanian IT-industry articles, with no match.
- A 3rd search (a combined "SINTETIC" + EUDR + lemn query) failed on a usage limit, so the coverage is thinner than planned (3 of 6 searches used, plus 1 error).
- Related context: Romania's state wood tracking system SUMAL 2.0 has documented problems (blockages, errors, no automated data checks), per
  [Newsweek RO](https://newsweek.ro/actualitate/aplicatia-care-urmareste-lemnul-taiat-sumal-a-cazut-sabotaj-sau-incompetenta) and
  [WWF Romania](https://wwf.ro/paduri/fraud-discovered-in-suceava-reveals-breach-in-sumal-2-0/). This is not about SINTETIC.
- Other EUDR timber DDS tools exist generally (e.g. Deeplai/TimberID, cubemos, osapiens), per
  [PEFC](https://pefc.org/cms/b999fadb-8521-4d4f-8d3c-4688f57fdced/news/10001145/the-timberid-supply-chain-solution-to-ensure-eudr-compliance) and
  [cubemos](https://cubemos.com/en/blog/eudr-software-for-the-timber-industry). They are not Romania-specific and are not SINTETIC.
- Complaints: none found about SINTETIC.
