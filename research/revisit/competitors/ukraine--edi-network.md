# EDI Network (АТС), Ukraine

Idea killed: C1079, e-TTN for carriers and shippers.

## Verdict: weak (as a barrier to a niche entrant). Caveat: the e-TTN market is a regulated multi-provider market, so the real barrier is accreditation, not EDI Network.

## Evidence
- ATC runs the EDI NETWORK platform. It is one of the first EDO (electronic document exchange) operators to pass technical compatibility checks and be authorized to offer e-TTN. Sources: https://buhplatforma.com.ua/news/108980-yaki-platformy-edo-vzhe-v-systemi-e-ttn ; https://buhplatforma.com.ua/news/109532-v-ukraini-ofitsiino-zapratsiuvala-e-ttn-koly-potribna-paperova-versiia
- EDI Network has its own e-TTN product documentation: https://wiki-v2.edin.ua/books/2025/page/edi-network-produkt-e-ttn/export/pdf (title only; I did not read the contents).
- Many other providers are in the same system: Vchasno, AgriChain, Deals, Zozengo, Comarch, InnLogist, Doc.Smart-Era. Source: https://mind.ua/news/20250739-ukrayina-testue-elektronni-ttn-dlya-pereviznikiv-mininfrastrukturi . Vchasno has a dedicated e-TTN page: https://vchasno.ua/en/ttn/ . EDI Network is therefore one of many, not a sole incumbent.
- The state registry is held by the Ministry of Infrastructure. EDI providers must pass state accreditation (Comarch overview: https://www.comarch.com/trade-and-services/data-management/news/the-e-ttn-project-in-ukraine/). A new entrant would need the same accreditation.
- Complaints: none found. The searches returned no app-store, forum or social reviews of EDI Network e-TTN. This is not evidence that the product is good, only that no public complaints surfaced in 3 searches.
- Momentum: e-TTN went officially live and EDI Network is an authorized operator. Its wiki has 2025 pages, so it looks actively maintained (weak signal).

## Fit gaps
Unverified. No evidence found on target segment, mobile or offline use, or small-carrier fit. EDI Network is traditionally a retail and supply-chain EDI vendor, so small carriers may be a secondary segment (unverified, my inference).

## Opening
A small-carrier or driver-friendly e-TTN front end is possible only through accreditation or by building on an accredited provider's API. EDI Network itself is not the obstacle.
