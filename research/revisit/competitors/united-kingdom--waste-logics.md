# Waste Logics (united-kingdom)

Idea killed: C1098 DWT phase 1 for receiving sites.

## Verdict: strong

Established, actively sold, full-suite waste operations software (skip hire, trade waste, brokerage, transfer stations, recycling) already serving receiving sites, with existing customers and accounting integrations. Evidence on complaints is thin because the search budget was cut short (see below).

## Evidence
- Capterra and GetApp list it as a commercial product used in the UK, Ireland and Australia, from owner-operated skip firms to operators with 20,000+ movements a month. Sources: https://www.capterra.com/p/135137/Waste-Logics/ , https://www.getapp.co.uk/software/2049475/waste-logics
- Integrates with Xero, Sage, QuickBooks, Pegasus, SAP B1 and Kashflow. Sources: https://www.accountsiq.com/integrations/waste-logics , https://www.softguide.com/program/waste-logics
- Access Group's comparison page says Waste Logics is building API integration for Digital Waste Tracking readiness, and notes that no public Waste Logics statement on this was found. It is a competitor's page, so treat it as biased. Source: https://www.theaccessgroup.com/en-gb/waste-management/resources/weighsoft-comparisons/access-weighsoft-vs-waste-logics/
- A search summary reported that sources say Waste Logics has no public API. Unverified: I did not open the underlying pages.
- Complaints: none found. Only 2 of the 6 permitted searches returned results. The first search (reviews and complaints) failed with a usage-limit error and was not retried successfully, so no review content on G2, Capterra, Trustpilot, Reddit or app stores was read. This is a gap, not a finding of "no complaints".
- No search in the local language was run (UK, English only).

## Pricing
Not published. Capterra and GetApp say to contact the vendor for a quote. A generic industry range of $75-250 per user per month appeared in an unrelated pricing guide and is not specific to Waste Logics (unverified for this product).

## Fit gaps
- No public API (unverified, see above), which matters for DWT submission by receiving sites.
- DWT readiness is described as "being built", with no public confirmation of a shipped Defra DWT integration. Unverified.
- Targets established operators with real volumes, so very small sites may be underserved. Inferred from its positioning, unverified.

## Opening
A narrow, cheap DWT-only receiving-site tool could serve small sites that don't want a full suite, but only if Waste Logics' DWT integration stays unshipped. It is one of about 25 Defra-listed vendors, so the field is crowded.
